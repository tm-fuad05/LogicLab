# 🧪 LogicLab — Interactive React & JS Logic Playground

**LogicLab** is a modern, interactive laboratory built with React 19 and TypeScript. It features a curated collection of real-world JavaScript and React UI logic patterns. The platform provides a playground environment for exploring data processing algorithms, state management, timer patterns, and DOM interactions.

🌐 **Live Demo:** [mylogiclab.vercel.app](https://mylogiclab.vercel.app)

---

## ⚡ Key Features & Logic Modules

- 📊 **Data Processing**: Array filtering, searching, pagination, and sorting logic.
- 📝 **Form Logic**: Dynamic form validation, multi-step forms, and input state handling.
- ⏱️ **Timers & Time Management**: Countdowns, stopwatches, intervals, and timer controls.
- 🔄 **Async Feedback**: Async data fetching, debouncing, throttling, and loader states.
- 📜 **Scroll & DOM Interactions**: Infinite scrolling, scroll progress, and element positioning.
- 💾 **Storage & Persistence**: LocalStorage, SessionStorage, and state persistence handlers.
- 👁️ **Visibility & Observers**: Intersection Observer triggers and element visibility tracking.
- 🚀 **Advanced Patterns**: Custom hooks, complex state conditionals, and performance optimizations.

---

## 🛠️ Tech Stack

- **Core Framework**: [React 19](https://react.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Routing**: [React Router v7](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 💻 Getting Started (Local Setup)

1. **Clone the repository:**
```bash
git clone https://github.com/tm-fuad05/LogicLab.git
cd react_and_js_logic_project
```

2. **Install dependencies:**
```bash
npm install
```

3. **Start the development server:**
```bash
npm run dev
```

4. **Build for production:**
```bash
npm run build
```
